Kế hoạch: Module Tổng Hợp B410 (Kiến trúc Native COM)

1. Hợp đồng chuyển giao & Kiến trúc mới

Mục tiêu: Gộp file B410 an toàn, đảm bảo giữ nguyên vẹn 100% hình ảnh (ngay cả hình nổi), merged cells, độ rộng cột, layout trang in bằng cách dùng Excel COM làm Engine chính thay vì ExcelJS. Bổ sung các cột truy vết nguồn gốc dòng dữ liệu.

Ràng buộc & Chống treo (Anti-hang):

  • Xử lý tuần tự từng file, tắt DisplayAlerts, có Timeout, dùng try/finally để giải phóng COM.
  • Không dùng taskkill để bảo vệ các file Excel đang mở khác của user.
  • File lỗi (có pass, macro hỏng) sẽ bị bỏ qua an toàn, tiếp tục file khác.
  • Tên sheet mới được cắt < 31 ký tự, xử lý trùng lặp tên.

Quy tắc xác định vùng dữ liệu: Quét dựa trên cột "Nội dung lỗi" để tìm LastDataRow. Bỏ qua các dòng subtotal/chữ ký ở cuối bảng gốc.
